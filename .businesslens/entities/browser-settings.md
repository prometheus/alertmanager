# Browser settings

Preferences the web UI keeps in the browser it runs in, apart from anything
the server keeps.

## Information kept

- **First day of the week** — the day the silence editor's calendar starts its weeks on
- **Default creator** — the creator last used for a new silence, offered for the next one
